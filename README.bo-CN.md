# ཚོགས་འདུ་སྣེ་ལེན་རམ་འདེགས་མ་ལག — སྐད་ཡིག་མང་པོའི་མ་ལག

སྐད་ཡིག་མང་པོར་རྒྱབ་སྐྱོར་ཡོད་པའི་ཚོགས་འདུ་སྣེ་ལེན་དོ་དམ་མ་ལག་ཅིག་ཡིན། སྤྱོད་མཁན་གྱིས་འདེམས་པའི་སྐད་ཡིག་ལ་གཞིགས་ནས་ངོས་པར་དང་གཞི་གྲངས་རང་འགུལ་གྱིས་བསྒྱུར་ཏེ། རྒྱལ་ཁབ་དང་ས་ཁུལ་མི་འདྲ་བའི་མགྲོན་པོར་ས་གནས་ཅན་གྱི་མྱོང་ཚོར་སྤྲོད།

## ནུས་པ་གཙོ་བོ

1. **ཞུགས་མཁན་དོ་དམ** — ཁ་སྣོན། བཟོ་བཅོས། སུབ་པ། Excel་ནས་མཉམ་དུ་ནང་འདྲེན། གཞི་གྲངས་ཞིབ་བཤེར།
2. **ཚོགས་འདུའི་བསྡོམས་རྩིས** — ཞུགས་མཁན་དང་སྡོད་ཤག ལྟོ་ཆས། འགྲིམ་འགྲུལ་བཅས་ཀྱི་གྲངས་ཀ་དུས་ལྟར་མཐོང་།
3. **ངོས་པར་སྐད་ཡིག་མང་པོ** — མཐེབ་གཅུས་དང་ཁ་བྱང་། གསལ་འདེབས་བཅས་ཚང་མ་བསྒྱུར་ཡོད།
4. **གཞི་གྲངས་སྐད་ཡིག་མང་པོ** — དཔེ་སྟོན་གཞི་གྲངས་སྐད་ཡིག་ལྟར་འཚོལ་བཤེར་བྱེད་ཐུབ།
5. **མགྱོགས་མྱུར་མཐོང་བྱ** — ཐོ་འགོད་མི་དགོས་པར་དཔེ་སྟོན་ལྟ་ཐུབ།

## ལག་རྩལ་གྲུབ་ཆ

- Frontend: JavaScript རྐྱང་པ། སྐད་ཡིག་བརྗེ་སྒྱུར་གྱི་ i18n རང་སྒྲིག
- Backend: Node.js + Cloudflare Workers
- གཞི་གྲངས་མཛོད: Cloudflare D1 (SQLite)
- ཉར་ཚགས: Cloudflare Pages
